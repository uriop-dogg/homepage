Woolyのホームページ

index.htmlを開くと表示できます。外部ライブラリやビルド、JavaScriptは不要です。

GitHub Pagesへの配置
index.html、en.htmlとassetsフォルダー全体を、公開する場所へ同じ構成でアップロードしてください。sourceとREADME.txtは制作資料のため公開不要です。記事ページと独立して配置できます。

更新
表示内容はindex.html、デザインはassets/home.cssです。source/links.jsonとリンク集.txtは一覧の記録です。JSONの変更のみでは画面は変わりません。リンク追加時はindex.htmlも更新してください。
記事名・アプリ名・日付・URLは提供一覧どおりです。
